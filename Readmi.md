# Language Detector

This is a simple Language Detector project built using Machine Learning. It detects the language of the text entered by the user.

## Technologies Used

### Frontend
- React
- Vite

### Backend
- Python
- Flask
- Joblib
- Scikit-learn

## Project Structure

```
project/
│── backend/
│   ├── app.py
│   ├── train_model.py
│   └── my_own_language_detector.joblib
│
│── frontend/
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── vite.config.js
│
├── requirements.txt
└── README.md
```

## How to Run

### Backend

```bash
cd backend
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Features

- Detects the language of input text
- Simple user interface
- Fast prediction
- Machine Learning model using Joblib
